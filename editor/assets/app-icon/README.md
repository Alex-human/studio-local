# Studio Local icon

Dark celestial-blue S on black, Liquid Glass style.
Generated with the built-in image generator. `StudioIcon.png` is the master;
`StudioIcon.icns` contains macOS 16–1024 px representations scaled with sips and
packaged losslessly with `package.mjs` (iconutil rejected the valid-size iconset here).
`build.command` installs the ICNS and declares CFBundleIconFile for every build.

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for Studio Local. Create one square 1024x1024 icon, front-facing orthographic, not a mockup. A single large uppercase "S", bold smooth geometric sans-serif, perfectly legible at small Dock sizes, centered on a deep black rounded-square tile. Dark celestial blue / rich azure cyan glass S, base tone around #1687B8 with restrained brighter ice-blue edge highlights, not pale pastel, not purple. Liquid Glass aesthetic: softly rounded dimensional glass, subtle refraction, polished beveled edges, elegant glossy depth; black obsidian glass background with very subtle edge reflections. The S occupies about 60% of tile height with ample balanced padding. Tile occupies about 90% of canvas, macOS continuous rounded corners, genuine transparent background outside tile. No other letters, no app name, no camera, no play triangle, no decoration, no scene, no watermark. Strong simple silhouette, premium restrained finish.
